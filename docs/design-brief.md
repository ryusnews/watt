# WATT 디자인 지시문 (Design Brief)

> 이 문서만 보고 디자인할 수 있게 썼다. Claude Design(또는 다른 디자인 도구)에 그대로 넣어도 된다.
> 결과물: 아래 "산출물" 항목의 아트보드 + 디자인 토큰. 개발자가 HTML/CSS 로 옮긴다.

## 1. 제품
- **이름:** WATT — *WoW AI Translation Tool*. 로고·창 제목에는 **WATT** 만 쓴다.
- **한 줄 설명:** 온라인 게임(월드 오브 워크래프트 클래식) 채팅을 실시간으로 읽어 한국어로 보여 주고, 한국어로 쓰면 영어·중국어·러시아어로 바꿔 주는 **PC용 통역 프로그램**.
- **사용자:** 아시아·글로벌 서버에서 외국 플레이어와 파티를 짜는 한국 게이머. 명령줄(CLI)을 모르는 사람도 쓸 수 있어야 한다.
- **동작 방식(디자인에 드러나야 할 신뢰 요소):** 게임 화면의 채팅창을 **읽기만** 한다(게임 파일·메모리를 건드리지 않음). 번역은 **내 PC 안의 AI**(Ollama + Gemma 4)로 하므로 채팅이 외부로 나가지 않는다. 게임에 자동 입력하지 않는다(클립보드 복사, 또는 붙여넣기까지만).
- **가장 중요한 인상:** "해킹 툴·불법 프로그램"처럼 보이면 안 된다. **정돈되고 믿을 만한 정식 소프트웨어** — 차분한 여백, 일관된 아이콘, 상태가 한눈에 보이는 화면. 네온 과잉·해골·매트릭스풍·게임 로고 금지.

## 2. 브랜드
- **콘셉트:** 와트(전력 단위) + 말풍선(통역). 로고 마크 = 말풍선 안의 번개, 또는 번개 모양 말풍선. 단순한 기하 도형, 16px 파비콘에서도 알아볼 수 있게.
- **색:** 짙은 남색 바탕(#0A0D12 근처) + **전기 노랑**(#FFC83D → 주황 #FF9A1F 그라데이션은 포인트에만). 상태색: 정상 초록, 주의 주황, 오류 빨강, 정보 파랑.
- **언어 색(채팅 언어 표시 칩):** 영어 파랑, 중국어 빨강, 러시아어 보라, 일본어 민트, 한국어 회색.
- **테마:** 다크만(게임 옆에 켜 두는 도구).
- **상표:** 블리자드·WoW 로고, 게임 아트, 게임 폰트 사용 금지. 정보 화면에 "World of Warcraft는 Blizzard Entertainment의 상표이며 WATT는 비공식 도구입니다" 문구.

## 3. 기술 제약 (반드시 지킬 것)
- **런처 창:** Windows 데스크톱 앱. Edge WebView2 안에서 HTML/CSS 로 그린다. 기본 **1120×740**, 최소 960×640. **테두리 없는 창** — 직접 그린 제목 표시줄(높이 40px, 끌어서 창 이동, 최소화·닫기 버튼 오른쪽 위).
- **글꼴:** 인터넷 없이 동작해야 하므로 웹 폰트·CDN 불가. **Segoe UI Variable / Malgun Gothic(맑은 고딕)** 기준으로 디자인. 숫자·단축키는 Cascadia Mono / Consolas.
- **아이콘:** 선 아이콘(1.75px 선, 둥근 끝) — 인라인 SVG 로 옮길 수 있게 단순하게.
- **게임 위 창 2개는 다른 기술(tkinter)로 그린다:** 둥근 모서리·그림자·그라데이션·부분 투명 **불가**. 단색 면, 1px 테두리, 창 전체 투명도(0.6~1.0), 글자 색·굵기만 쓸 수 있다. 이 제약 안에서 디자인.
- 한국어 UI. 버튼·문구는 짧고 쉬운 말(예: "설치", "다시 찾기", "통역 시작").

## 4. 화면(아트보드) — 모두 1120×740

### 공통 틀
- 왼쪽 **사이드바**(약 232px): 로고 + WATT 글자 + 작은 부제("AI 채팅 통역"). 메뉴: **홈 · 환경 설정 · 번역 설정 · 용어 사전 · 정보**. 환경 설정에 할 일이 남았으면 메뉴에 작은 주황 점.
- 사이드바 아래: 번역 엔진 상태 알약("AI 엔진 준비됨 · gemma4:12b" 초록 점 / "꺼짐" 회색) + 버전(v0.1.0).
- 오른쪽 아래 **알림(토스트)** 자리: "설정 저장됨", "모델 받기 완료" 같은 짧은 알림.

### A. 홈(대시보드) — 2가지 상태
1. **통역 꺼짐**: 큰 원형 **전원 버튼**("통역 시작"). 옆에 설명("게임 채팅을 읽어 한국어로 보여 줍니다") + 옵션 2개:
   - "보내기 입력창" 켜기/끄기 + 단축키 키캡 `Ctrl` `Shift` `K` ("한국어로 쓰면 영어로 바꿔 클립보드에 넣습니다")
   - "원문 함께 보기" 켜기/끄기
2. **통역 켜짐**: 전원 버튼이 노랗게 빛남("통역 중"), 번역이 흘러오는 **최근 번역 목록**.
- 상태 카드 4개(한 줄): **AI 엔진**(Ollama 0.34 · gemma4:12b · VRAM 7.5GB) / **글자 인식**(4개 언어 준비됨) / **게임**(실행 중 · 2560×1440) / **채팅 영역**(688×325 · 찾음). 각 카드: 아이콘, 값, 보조 문구, 상태(정상/주의/오류).
- 숫자 3개: 오늘 번역 **128건**, 표시까지 평균 **1.3초**, 읽기 속도 **240ms**.
- **최근 번역 목록**(예시 데이터, 원문은 작게 흐리게):
  - `영어` [6] Thornvale — "통곡의 동굴 탱커 구함, 귓 주세요" / LF tank for WC, pst
  - `중국어` [1] 影月 — "통곡의 동굴 3명 있음 2명 더 구함, 탱커·힐러 구함" / 哀嚎3=2 来 T,N
  - `러시아어` [6] Бродяга — "성난불길 협곡 같이 가실 분?" / Кто в Огненную пропасть?
  - `영어` [2] Mirelle — "리넨 옷감 1묶음 50실버에 팝니다" / WTS linen cloth stack 50s
  - `중국어` [1] 青山 — "20레벨 사냥꾼, 통곡의 동굴 파티 찾음" / 20LR 求组 AH
- 목록이 비었을 때(빈 상태) 모양도 하나.

### B. 환경 설정(설정 마법사)
맨 위 요약: 진행 고리(예: 5/7) + "모두 다시 점검" 버튼. 아래로 **7단계 카드**. 단계마다 번호/체크 아이콘, 제목, 상태 태그(완료 초록 · 필요 주황 · 진행 중 · 오류 빨강), 설명, 행동 버튼, 필요하면 진행 막대.
1. **내 PC 확인** — Windows 11, 메모리 32GB, 그래픽카드 NVIDIA GeForce RTX 5080 (16GB), 남은 디스크 764GB. 판정 문구: "추천 모델을 무리 없이 돌릴 수 있습니다".
2. **글자 인식 언어 팩(Windows OCR)** — 칩 4개: 영어 ✓, 한국어 ✓, 중국어(간체) ✓, 러시아어 ✗. 버튼 "빠진 언어 설치"(방패 아이콘 = 관리자 권한 필요) + 안내 "Windows 권한 확인 창이 뜹니다. 설치에 몇 분 걸릴 수 있습니다".
3. **AI 실행기(Ollama)** — 설치됨/실행 중/버전. 없으면 "설치"(공식 설치 파일, 약 1GB), 꺼져 있으면 "켜기".
4. **번역 모델** — 모델 카드 3개 중 선택: **Gemma 4 12B**(추천 · 검증됨 · 받기 7.7GB · VRAM 약 8GB · "가장 정확") / Gemma 4 E4B(6.6GB · 검증 전) / Gemma 4 E2B(4.6GB · 가벼움 · 검증 전). **받는 중 상태**: 진행 막대 62% · "3.1GB / 7.7GB · 남은 시간 약 2분" · 취소 버튼.
5. **게임 폴더와 채팅 글꼴** — 찾은 게임 목록(라디오): 클래식 베타 `_classic_beta_` (실행 중, 애드온 0.2.0 설치됨) / 기념 서버 `_anniversary_` (애드온 없음) / 리테일 `_retail_` (지원 안 함, 흐리게). 버튼 "글꼴 애드온 설치". 안내: "중국어·러시아어 채팅이 □로 깨지지 않게 하는 글꼴입니다. 게임을 완전히 다시 켜야 적용됩니다".
6. **채팅 영역 찾기** — 버튼 "지금 찾기"(게임이 켜져 있어야 함). 결과: 찾은 채팅창 미리보기(검은 배경 채팅 캡처 이미지 자리 688×325 비율) + "688×325 · 줄 높이 20px · 채팅 6줄 인식". 팁 목록: 채팅 배경 불투명 검정 / 글자 크기 14 이상 / 글자 사라짐 끄기 / 번역할 채널만 모은 전용 탭.
7. **번역 시험** — 버튼 "시험해 보기". 결과 2줄: `받기` "哀嚎4=1 来ms" → "통곡의 동굴 4명 있음, 사제 1명 구함" (0.9초) / `보내기` "성불 탱 구해요 귓 주세요" → "LF tank for RFC, pst" (0.4초).
- 모두 끝나면 맨 위에 축하 배너 "준비 완료 — 홈에서 통역을 시작하세요".

### C. 번역 설정
카드 3~4개, 각 줄은 "제목 + 설명 | 조작".
- **보내기(한국어 → 외국어):** 기본 언어(분절 버튼: 영어 · 중국어 · 러시아어 · 일본어) / 보내는 방식(라디오: "클립보드에 복사 — 게임에서 Ctrl+V" · "채팅창에 붙여넣기 — Enter는 직접") / 단축키 표시(Ctrl+Shift+K, 게임 중 Ctrl+Enter).
- **통역 창:** 글자 크기(슬라이더 9~18) / 투명도(60~100%) / 보일 줄 수(5~20) / 원문 함께 보기(스위치) / "창 위치 처음으로" 버튼.
- **AI 엔진:** 사용할 모델(드롭다운) / "모델 미리 올려 두기"(스위치: 첫 번역 대기 없애기).
- **기록:** 분석용 기록 저장(스위치 + "번역 품질을 높이는 데 씁니다. 내 PC에만 저장") / "기록 폴더 열기".

### D. 용어 사전
- 위: 검색창("통곡, WC, 哀嚎 …") + 분류 칩(전체 · 던전 · 공격대 · 지역 · 도시 · 직업 · 역할 · 채팅 줄임말 · 확인 필요).
- 표: **한국 이름 | 한국 줄임말 | 영어 | 중국어 | 러시아어**. 예:
  - 통곡의 동굴 | 통곡 | WC (Wailing Caverns) | 哀嚎洞穴 · 哀嚎 · AH | Пещеры Стенаний
  - 성난불길 협곡 | 성불 | RFC (Ragefire Chasm) | 怒焰裂谷 · 怒焰 · NY | Огненная пропасть
  - 사냥꾼 | 냥꾼 | Hunter | 猎人 · LR | Охотник
  - 파티 찾음 | 파티 찾아요 | LFG | 求组 | ищу группу
- "확인 필요" 표시(작은 주황 태그)가 붙은 줄임말이 몇 개 있다.

### E. 정보
로고 크게 + WATT + v0.1.0 + 한 줄 설명. **개인정보·안전 약속 3가지** 카드(내 PC 안에서만 번역 / 게임 파일·메모리 건드리지 않음 / 자동 입력 없음). 상표 고지. 오픈소스·라이선스 목록(Ollama — MIT, Gemma 4 — Gemma Terms of Use, Sarasa Gothic — SIL OFL 1.1, pywebview — BSD). "기록 폴더 열기" 버튼.

### F. 첫 실행 환영 화면(선택)
"WATT에 오신 것을 환영합니다" + 3단계 안내 그림(① 환경 설정 → ② 게임 켜기 → ③ 통역 시작) + "시작하기" 버튼.

### G. 게임 위 창 2개 (tkinter 제약 — 3장 참고)
1. **통역 창**(기본 약 520×300, 크기 조절 가능): 윗줄 얇은 막대("⚡ WATT" 노랑 + 상태 "번역 12건 · 최근 0.9초" + 닫기 ✕). 본문: 메시지마다 `언어 칩(글자색만)` + `[6] 이름`(작게, 회색) / 다음 줄에 **한국어 번역**(밝게) / 원문 보기 켜면 그 아래 원문(흐리게). 번역 중인 줄은 흐린 글자 + "번역 중…". 오른쪽 아래 크기 조절 표시 ◢.
2. **보내기 입력창**(약 620×130): 윗줄("⚡ WATT" + "한국어 → 영어 · 클립보드에 복사"), 입력칸(한 줄, 큰 글자), 결과 줄(초록: "LF tank for RFC, pst — 클립보드에 복사됨"), 맨 아래 작은 도움말("Enter 번역 · Tab 언어 · F2 방식 · Esc 닫기").
- 둘 다 게임 화면 위에 떠 있는 모습(어두운 게임 배경 위)으로 한 장.

## 5. 산출물
1. 위 A~G 아트보드(A는 2가지 상태, B는 "진행 중" 단계 포함).
2. **디자인 토큰 표:** 색(바탕 3~4단계, 선, 글자 3단계, 포인트, 상태색, 언어색), 글자 크기 단계, 둥글기, 간격, 그림자.
3. **컴포넌트:** 버튼(주·보조·유령·위험, 작게), 태그/상태 알약, 스위치, 분절 버튼, 슬라이더, 진행 막대, 카드, 단계 카드, 표, 토스트, 키캡.
4. 로고 마크(SVG로 옮길 수 있게 단순한 도형) — 큰 크기와 16px 크기.
