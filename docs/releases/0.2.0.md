# WATT 0.2.0 — 인식 안정판

어떤 채팅 설정(기본 채팅 · EllesmereUI · Prat · 작은 글꼴 · 키운 채팅창)에서도 외국어 채팅을 놓치지 않고 바르게 번역한다. 0.1.x(0.1.1 – 0.1.77)의 실제 게임 모니터링 결과를 담았다.

## 권장 설정
번역 설정 → **AI 글자 인식**에서 한국어 · 중국어 · 러시아어를 켠다(환경 설정 마법사의 권장 단계, 약 60MB, PC 안에서만 돌아감). 기본은 CPU — GPU 를 켜면 VRAM 1–2GB 를 더 쓴다. 유럽어(ES · DE · FR · PT)가 많은 서버면 '유럽어'도 켠다.

## 바뀐 점
**인식**
- AI 글자 인식(PaddleOCR) — 언어마다 켜고 끄기, 그 언어가 화면에 보일 때만 모델을 돌린다
- Windows 그래픽 캡처로 게임 화면을 받고, 채팅이 밀린 만큼 새 줄만 읽는다
- 한 줄에 한국어 채널 · 영어 이름 · 외국어 본문이 섞여도 콜론 뒤를 보낸 사람 언어로 읽는다
- Prat · 작은 글꼴 · 채팅 시간 표시([23:10:02]) · 레벨 표시(20:이름) · 여러 줄 메시지 · 외침 · 귓속말
- 라틴 문자 줄마다 언어 짐작(EN · ES · DE · FR · PT · IT), 원문 언어 표시

**번역**
- 용어 사전(175개) — 던전 · 지역 · 직업 · 병음 약자(NY · AH · 车头) · 파티 은어, 런처에서 고치기
- 보내기 언어 9개(EN · ZH · TW · RU · ES · DE · FR · PT · JA) — 입력창에서 눌러 고르기 · Tab / Shift+Tab
- 한국어 메시지는 번역 없이 그대로, 다시 올린 글은 ↻ 로 — 통역 창이 채팅창과 같은 순서
- 광고 접기, 메시지 오른쪽 클릭으로 그 사람 숨기기 · 광고 아님 · 광고로
- 번역이 밀리면 더 가벼운 모델을 권하고, 모델을 바꾸면 쓰던 모델을 내린다(VRAM)

**런처**
- 창 크기 조절 · 최대화 · 크기에 맞춘 배치, 깜빡이지 않는 번역 목록, 언어 탭
- 바뀐 파일만 받는 업데이트, 30분마다 확인, 업데이트 뒤 통역 이어서 켜기
- 보내기 입력창 단축키 바꾸기, 통역 창 · 입력창이 화면 밖이면 되돌리기(모니터 · 해상도가 바뀐 뒤)
