# 게임 설정 가이드

WATT 는 게임 화면의 채팅창을 찾아 그 부분만 읽습니다. 아래 설정이 인식률을 좌우합니다.

## 게임 화면
| 항목 | 권장 | 이유 |
|---|---|---|
| 화면 모드 | **창 모드(최대화)** 또는 전체 창 모드 | 전체 화면 전용 모드는 캡처와 통역 창 표시가 안 됩니다 |
| 해상도·모니터 | 제한 없음 | 게임 창을 옮기면 따라가고, 크기가 바뀌면 다시 찾습니다 |

## 채팅창
| 항목 | 권장 | 이유 |
|---|---|---|
| **배경** | **불투명한 검정**(투명도 0%) | 채팅창을 배경색으로 찾습니다. 게임 화면이 비치면 글자를 잘못 읽습니다 |
| **글꼴** | ChatFontCJK 애드온(환경 설정 5단계에서 설치) | 중국어·러시아어가 □ 없이 그려져야 읽을 수 있습니다. 게임을 완전히 다시 켜야 적용 |
| **글자 크기** | 14 이상(줄 높이 20px 이상) | 작으면 한자·이름이 깨집니다 |
| 글자 사라짐(페이드) | **끔** | 사라지는 중인 반투명 글자는 못 읽습니다 |
| 채팅 탭 | 번역할 채널만 모은 **전용 탭** | 시스템 메시지가 섞이면 줄이 밀립니다 |
| 위치·크기 | 고정, 다른 UI 와 겹치지 않게, 6~10줄 | 겹친 창·말풍선이 섞입니다 |

## 용어 사전
`translator/wow_terms.json` 하나를 받기·보내기가 함께 씁니다. 항목마다 한국 이름·한국 줄임말·영어 이름·영어 약어·중국어·러시아어를 묶습니다.

- 보내기: "통곡 가실분 모십니다" → 통곡 = WC → `LF for WC`
- 받기: RFC · 怒焰 · Огненная пропасть → 성난불길 협곡
- 중국 플레이어는 영어 약어 대신 **한자 병음 첫 글자**를 씁니다: `AH` = 哀嚎 = 통곡의 동굴, `20LR` = 20레벨 猎人(사냥꾼). `zh_only: true` 항목은 중국어가 섞인 글에서만 씁니다.
- `verify` 표시가 있는 줄임말은 확인이 필요한 것 — 실제로 안 쓰면 고치거나 지워 주세요(PR 환영).
- 일상어와 겹치는 줄임말은 넣지 않습니다(예: 기사·마나).
- 바꾼 뒤 확인: `python -m eval.quick_translate`

## 알아 둘 것
- 게임의 채팅 기록(`/chatlog`)은 실시간으로 쓰이지 않아 화면을 읽습니다.
- 기록(`%LOCALAPPDATA%\WATT\logs`)에는 채팅 내용이 들어 있으니 공유할 때 주의하세요.
